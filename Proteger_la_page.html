Protéger la page par mot de passe

Chiffre la suite Altesia Finance pour la publier sur GitHub Pages sans que personne ne puisse l'ouvrir ni lire son code sans le mot de passe. Tout se passe dans ce navigateur : le mot de passe n'est envoyé nulle part.

 
Ensuite
  1. Dans le dépôt GitHub Finance-Analysis : « Add file » → « Upload files » → déposez le fichier index.html créé → « Commit changes ».
  2. Après une minute, l'adresse du site demande le mot de passe.
  3. Gardez la phrase de passe dans un gestionnaire de mots de passe : elle ne peut pas être retrouvée.
  4. À chaque nouvelle version de la suite, repassez par cet outil avec la même phrase de passe (vos données mémorisées restent disponibles).
